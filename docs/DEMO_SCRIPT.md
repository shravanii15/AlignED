# Loom demo script (about 90 seconds)

Record in Chrome at 1440 wide, browser zoom 100%, bookmarks bar hidden, notifications off. Open
https://aligned-shravanikulkarni.streamlit.app first and let it wake up before you press record.

| Time | On screen | Say |
|---|---|---|
| 0:00 | Home page hero | "AlignED checks whether graduate programs teach what employers ask for. I compared 1,378 courses from 13 programs with 1,660 job postings, and tested every gap." |
| 0:12 | Scroll to the Python card and the chart | "For example, Python is in 40% of postings and in none of 295 courses in this catalog. That gap is statistically significant, and it shows up in 10 of the 13 programs." |
| 0:28 | Click Match, then Match a Job. Paste a real job posting from your target role, click check | "If you found a job you want, paste it. Here is what it asks for, what I already have, and what to learn first." |
| 0:50 | Click Explore, then Skill Gaps | "Or pick a program and see the tested gaps with the evidence behind each one." |
| 1:05 | Click Evidence, then Model Evaluation | "I also tested my own method. An LLM looked better on my tuning data, then lost on 50 unseen items, so I shipped the simpler keyword method." |
| 1:20 | Click Data Health, then About | "A daily pipeline validates the job feed, and the code, tests and case study are on GitHub." |
| 1:30 | Stop | |

Tips: pause two seconds after each click so people can read. Keep your cursor still while talking. Trim any loading
spinners in Loom. Use a job posting that really does show a clear gap so the match result is interesting. Do not read the
numbers off the screen word for word; say the one that matters and let the viewer see the rest.
